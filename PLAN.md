# Solflare для macOS: архитектура, статус и ограничения

Нативное macOS-приложение на SwiftUI с фиксированным окном **1200 × 800** (плюс полоса заголовка 20 pt) и локальным self-custodial бэкендом без сервера.

---

## 1. Архитектура

```
SolflareMac/
├── Solflare.xcodeproj
├── Solflare.entitlements          App Sandbox + network client
├── Tools/solana_oracle.py         независимая сверка ключей/адресов (hashlib, без пакетов)
├── Packages/SolflareCore/         бэкенд без UI: Crypto · Network · Wallet · Transactions + тесты
└── Solflare/                      (синхронизированная папка Xcode 16)
    ├── App/            SolflareApp, AppDelegate, MainWindow, RootView, AppRouter, AppModel, DebugLaunch
    ├── DesignSystem/   Palette, InterFont, Typography, SVGIcon, SVGPathParser, Icons.generated, ButtonStyles, Controls, Motion, Layout
    ├── Domain/         Models, Formatting
    ├── Services/       WalletService (protocol) · LiveWalletService · KeychainVault · EffectStore · MockWalletService
    ├── Features/       Onboarding · Shell · Portfolio · Assets · Markets · Activity · Settings · Overlays
    └── Resources/      Assets.xcassets, Fonts (Inter, woff2), Preloader
```

Ключевые решения:

1. **Окно**: `NSWindow` + `NSHostingView` (создаётся в `MainWindow`), контент строго 1200×800; сверху полоса заголовка 20 pt с подписью «Solflare» (по просьбе пользователя), поэтому окно 1200×820, resize / zoom / fullscreen отключены, тёмная схема. Сцена SwiftUI `Window` не подошла: она добавляла к размеру высоту заголовка (1200×828).
2. **Вёрстка**: абсолютное позиционирование через helper `abs(x:y:w:h:)` — фиксированная геометрия без «плавающих» отступов.
3. **Иконки**: векторные path-данные в `Icons.generated.swift`, рендерятся как `Shape`.
4. **Шрифт**: Inter (woff2 в ресурсах приложения, CoreText читает woff2 напрямую).
5. **Данные**: экраны зависят только от `AppModel` и протокола `WalletService`. В работе — `LiveWalletService` (локальный кошелёк); `MockWalletService` — демонстрационные данные для проверки вёрстки (`-debugMock 1`).
6. **Навигация**: онбординг меняет только левую панель (карусель живёт), приложение — только контент справа (сайдбар/шапка постоянны).

## Запуск

```bash
cd SolflareMac
xcodebuild -project Solflare.xcodeproj -scheme Solflare -configuration Debug build
```

Либо открыть `Solflare.xcodeproj` в Xcode и нажать ⌘R.

## 3. Локальный self-custodial бэкенд

Выбран вариант **B**: сервера нет, ключи выводятся на устройстве, данные берутся из публичных источников.

### Что где

| Слой | Реализация | Проверено |
|---|---|---|
| Мнемоника | BIP-39 (генерация из `SecRandomCopyBytes`, 12/24 слова, контрольная сумма, словарь с каноническим SHA-256) | векторы Trezor, словарь |
| Ключи | SLIP-0010 ed25519, путь `m/44'/501'/0'/0'` (как Solflare/Phantom) → адрес Base58 | официальный вектор SLIP-10 + независимый Python-оракул |
| Хранение | Связка ключей macOS (generic password, `WhenUnlockedThisDeviceOnly`); фраза нигде больше не пишется и не логируется | запуск → перезапуск → автовход |
| Баланс | Solana JSON-RPC: `getBalance`, `getTokenAccountsByOwner` (Token + Token-2022) | живой mainnet |
| Токены и цены | Jupiter `tokens/v2` (имя, символ, иконка, цена, 24ч-изменение), спам без цены отфильтрован | живой mainnet |
| Валюты | CoinGecko `exchange_rates` → EUR / GBP, кэш 10 мин | тест + живой |
| Рынок | Jupiter `toptraded/24h` (цена, mcap, объём, ликвидность, holders), поиск по имени/символу/mint | живой |
| Активность | `getSignaturesForAddress` + `getTransaction` → чистые изменения по активам → Received / Sent / Swapped / Interaction | 8 тестов + живой |

Запуск тестов ядра: `cd Packages/SolflareCore && swift test` (живые прогоны: `SOLFLARE_LIVE=1 swift test --filter LiveNetworkTests`).

### 3.1 Отправка средств (SOL и SPL-токены)

Поток: **форма → обзор → подтверждение системой (Touch ID / пароль macOS) → подпись → отправка → ожидание подтверждения**.

| Шаг | Что происходит |
|---|---|
| Проверка | Чистая функция `SendPlanner` (Core): адрес, баланс, комиссия, аренда, остаток на счёте. Пороги берутся из RPC, не из констант |
| Защита получателя | Блок: свой адрес, burn-адреса, адреса программ и токен-счетов; для токенов — **перехваченный ATA** (счёт существует, но принадлежит другому владельцу), замороженный и «не тот» токен-счёт |
| Обзор | Адрес целиком, сумма, точная комиссия (`getFeeForMessage`), отдельно — аренда за новый токен-счёт получателя |
| Подпись | Ключ выводится из Keychain только на момент подписи; перед этим — `LocalAuthentication` |
| Отправка | `finalized` blockhash, повтор с новым при `BlockhashNotFound`; сверка суммы с обзором перед подписью |
| Подтверждение | опрос `getSignatureStatuses`, определение «просрочена» по высоте блока |

Точки входа: кнопка **Send** рядом с Deposit в Portfolio и в строке актива в Assets.

**Как проверено (без реальных отправок):**

- сообщение системного перевода совпало **побайтно с двумя реальными транзакциями mainnet**;
- сообщения токен-перевода и создания ATA сверены с независимым оракулом;
- **mainnet принимает нашу подпись** (`AccountNotFound` — после sigverify), а испорченную отклоняет (`SignatureFailure`);
- инструкции `CreateIdempotent → TransferChecked` **исполняются в mainnet** (`simulateTransaction`: success);
- адрес ATA совпал с **40 из 40** реальных токен-счетов;
- порог аренды: 650 240 — проходит, 650 239 — сеть отклоняет (правило планировщика совпадает с сетью);
- живой путь приложения до экрана обзора: реальная комиссия, реальные проверки получателя.

**Что обнаружила живая проверка (и учтено):**

1. Порог rent-exempt в сети **650 240**, а не привычные 890 880 — константы убраны.
2. Тестовые публичные кошельки «отравлены»: у них сменён владелец аккаунта и перехвачены ATA. Блокировки в планировщике сработали на реальных данных.
3. Балансировщик публичного RPC не успевает отдавать свежий `confirmed` blockhash — используется `finalized`.
4. CryptoKit подписывает Ed25519 с «hedged»-добавкой: подпись валидна, но не совпадает побайтно с детерминированной RFC 8032.

**Ограничения отправки:**

- **Ни одна транзакция не отправлялась в mainnet при разработке** (нет средств для тестов). Первую реальную отправку сделайте на минимальную сумму.
- Token-2022 не поддерживается (в списке отключён).
- Нет приоритетной комиссии (priority fee) и повторной рассылки: при перегрузке сети транзакция может истечь — тогда средства не списываются.
- Один получатель за раз; памятка (memo) не поддерживается.
- Адресной книги нет: защита от «подмены адреса» — полный адрес на обзоре и системное подтверждение.

### Настройки и безопасность (этап 9)

Дополнительные возможности:

| Что | Где | Как работает |
|---|---|---|
| Свой RPC | Settings → Advanced | Адрес только `https://`, перед сохранением проверяются `getGenesisHash` (кластер совпадает) и `getHealth`. Хранится в Keychain (может содержать ключ), на экране показывается только хост |
| Сети Mainnet / Devnet / Testnet | Settings → General | Переключает RPC; на тестовых сетях цены и «спам-фильтр» отключены, в шапке жёлтый бейдж, ссылка Solscan с `?cluster=` |
| Блокировка приложения | Settings → Security & Privacy | Off / On launch / после 1, 5, 15 мин, 1 ч бездействия; также при сне Mac и блокировке экрана, ⌘L. Смена настройки требует Touch ID / пароль |
| Показ фразы | Settings → Security & Privacy | После Touch ID / пароля; скрывается через 60 с; пока видна — окно исключено из записи экрана; буфер очищается через минуту |
| Подтверждение крупных переводов | Settings → Transfers | Порог в USD (50 / 100 / 500 / 1000 / всегда): нужно набрать последние 4 символа адреса. Цена неизвестна — подтверждение требуется |
| Только сохранённые адреса, адресная книга | Settings → Transfers | Адреса проверяются как публичные ключи; в форме отправки меню «Saved», на обзоре — имя получателя |
| Автообновление и «Refresh now» | Settings → General | 30 с / 1 мин / 5 мин / вручную; обновляются баланс, рынки и (если открыта) лента |
| Очистка локальных данных | Settings → Advanced | Кэш транзакций, иконки, метаданные, кэш портфеля; показывается размер |
| Hide balances on launch | Settings → Security & Privacy | Каждый запуск начинается со скрытыми балансами |
| About | Settings → About | Версия, лицензии, «Copy diagnostics» (без ключей, фразы и полного адреса) |

**Markets:** колонки PRICE и MARKET CAP сдвинуты вправо (+32 и +27 pt), заголовки колонок — кнопки сортировки (↓ → ↑ → сброс), справа от поиска фильтры: изменение за 24 ч, капитализация, ликвидность, холдеры + кнопка Reset. Иконки токенов грузятся через `RemoteImageStore`: кэш в памяти и на диске, SVG/WebP/PNG, при 429 у `ipfs.io` берутся запасные шлюзы (Pinata, 4everland, Filebase).

**Activity:** строка истории подсвечивается при наведении, нажатии и пока открыта панель; клик открывает боковую панель (как Receive/Send) с суммами, статусом, датой, типом, полными адресами отправителя и получателя (с именем из адресной книги), комиссией и подписью, кнопки «Copy signature» и «View on Solscan». Esc или клик по фону закрывают панель.

**Send → выбор актива:** поле Asset раскрывает плашку под собой (поверх формы): иконки токенов, название, остаток, отметка выбранного, «Not supported» для Token-2022. Стрелка переворачивается; закрывается выбором, кликом вне плашки или Esc.

**Плашки выбора (везде):** все поля Select (Currency, Network, Auto-refresh, App lock, Extra confirmation, фильтры Markets) и меню «Saved» в Send раскрываются кастомной плашкой под полем вместо системного меню: название + пояснение варианта, отметка выбранного, шеврон переворачивается. Рисуется одним слоем `DropdownLayer` поверх приложения, поэтому не обрезается прокруткой; закрывается выбором, кликом вне плашки, Esc, сменой экрана и блокировкой.

**Логотипы и прелоадер:** логотипы (`logo-wordmark`, `logo-mark` в `Assets.xcassets`) заменены на PNG пользователя в Welcome, Create wallet, All done, сайдбаре и на экране блокировки. Прелоадер `Resources/Preloader/solflare-preloader.mp4` проигрывается при каждом запуске приложения и плавно уходит в главную страницу (`-debugSkipPreloader 1` — пропуск в Debug для проверок экранов).

**Иконка приложения:** `Assets.xcassets/AppIcon.appiconset` (10 размеров 16–1024 px) собрана из `Solflare.icon` пользователя: жёлтый фон `#FFEF46` и чёрный знак `Vector.svg` в системной форме иконки macOS. Xcode 16 не умеет читать формат `.icon` (нужен Xcode 26), поэтому иконка отрендерена в PNG; в `project.pbxproj` задан `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`.

**Ограничения этапа:**
- Блокировка защищает интерфейс, но не Keychain: фраза остаётся в Keychain и доступна другим процессам пользователя в разблокированной сессии macOS.
- Устройство без пароля/Touch ID не сможет включить блокировку и показать фразу (macOS не даст пройти проверку).
- Devnet/Testnet: токены без метаданных показываются коротким адресом mint; цены нулевые.
- Если у токена нет доступного изображения, остаётся буква-заглушка.
- Адресная книга хранится в UserDefaults (не секретна, но и не синхронизируется).

### Известные ограничения

1. **Публичный RPC Solana ограничивает `getTransaction`** (на практике ~0.6 транзакции/с). Поэтому транзакции грузятся по одной с паузами, результат кэшируется на диск (подтверждённая транзакция неизменна), лента показывает строки по мере загрузки. Холодный старт ленты — до ~20 с, дальше мгновенно.
2. **Свой RPC** (Helius, QuickNode…) снимает это ограничение: Settings → Advanced → Custom RPC.
3. **Блокировка** (App lock) защищает интерфейс, но не заменяет защиту учётной записи macOS: фраза остаётся в Keychain.
4. Токены Token-2022 показываются, но отправка не поддерживается; нет priority fee и memo.
5. Неуспешные транзакции в ленту не попадают.
6. Источники данных (Jupiter, CoinGecko) бесплатные и могут изменить лимиты или формат.

### Безопасность

- Фраза: Keychain, `ThisDeviceOnly`, не попадает в логи, UserDefaults, кэш и аналитику; после «I saved my recovery phrase» удаляется из памяти интерфейса.
- Копирование фразы в буфер очищается через 60 секунд (если буфер не менялся).
- App Sandbox + только исходящая сеть.
- В Debug есть `-debugImportPhrase` — **только для публичных тест-фраз**, в Release не компилируется.
